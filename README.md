# Lab Environments for Azure DevTest Labs

Collection of lab environments which can be used for Proof-of-Concept and training purposes.

The setups are a reusable Azure-based deployment framework for hands-on course labs, including PowerShell, PKI, and future technical courses. Each course can define its own virtual machines, network, identities, services, sample data, and configuration while using a consistent method to deploy complete, ready-to-use environments.

For training centers, this eliminates any responsibility for deployments. It's the trainer that handles setup and provides repeatable environments with simpler preparation, predictable course delivery, easier scaling, and less dependence on local hardware.

For learners, it provides an isolated and consistent environment in which they can practise realistic administrative tasks, make changes safely, and work with the same starting configuration as the instructor and other participants.

## Mastering-PKI

For the Mastering PKI course. This includes four Windows VMs and (optionally) one Linux VM.

## PowerShell

For the PowerShell course. This includes three Windows VMs.
